## 每一列填什么

| 列 | 填什么 |
| --- | --- |
| 序号 | 1、2、3 |
| 类型 | `竞赛`。不要改成实习或考研 |
| 来源名称 | 你认得出来的名字，例如某个赛事官网、学院通知栏。用你看到的名称 |
| 网址 | 浏览器地址栏里的地址。没有公开网址就写 `未找到` |
| 更新频率 | `每天`、`每周`、`不定期`、`未知` 四选一 |
| 是否需要登录 | `是`、`否`、`未知` |
| 内容在哪里 | `网页`、`公众号`、`附件`、`其他` |
| 本月录入方式 | 保持 `只手动粘贴` |
| 我能否打开 | 你当场打开过，写成 `能打开` 或 `打不开` |
| 备注 | 打不开的原因，或「本周打开过，没有新通知」 |

## 怎么选这 3 个

1. 只选竞赛通知，不选实习招聘、考研院校或课程资料。
2. 优先选不登录就能打开的网页。
3. 打不开的不要硬凑进「能打开」。换一个来源，或把这一行标成 `打不开` 再另找。
4. 公众号和附件可以留在清单里，但不要为它们做机器人或定时抓取。

## 怎样算完成

- `templates/sources.csv` 有 3 行，类型都是竞赛，录入方式都是只手动粘贴。
- 至少 1 行是你刚刚打开成功的，`我能否打开` 为 `能打开`，网址是你地址栏里的那一条（或明确写了 `未找到` 且备注说明它在公众号或附件里）。
- 没有登录密码、cookie、学号。
