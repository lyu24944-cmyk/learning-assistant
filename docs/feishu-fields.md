# 飞书多维表格字段

示例数据是脱敏的，不代表真实学校或赛事。规范表在：

- `templates/records.example.json`
- `templates/records.example.csv`
- 飞书导入用：`templates/feishu-import.example.csv`（「未找到」已从日期列清空）

重新生成导入文件：

```bash
python3 -m src.export_feishu
```

## 为什么日期要拆一列

约定里的「截止日期」是字符串：`YYYY-MM-DD` 或「未找到」。飞书日期字段不能保存「未找到」。导入和建表时：

| 规范字段 | 飞书字段 | 飞书类型 | 未找到时怎么填 |
| --- | --- | --- | --- |
| 截止日期 | 截止日期 | 日期 | 留空 |
| （由截止日期派生） | 截止日期标注 | 单选：已识别 / 未找到 | 选「未找到」 |

其余字段两边同名。

## 建表

新建多维表格，数据表命名为「截止」。按下面建字段。单选的选项按表中文字建，不要多加空格。

| 字段 | 类型 | 选项或格式 | 谁来填 |
| --- | --- | --- | --- |
| 标题 | 文本 |  | 你，或从抽取 JSON 抄入 |
| 类型 | 单选 | 竞赛、实习、考研 | 本周只录入 `config/settings.json` 里的那一类 |
| 截止日期 | 日期 | 格式选年月日 | 公历日期；未找到则空 |
| 截止日期标注 | 单选 | 已识别、未找到 | 与截止日期一起填 |
| 来源链接 | 文本 | 超链接字段也可以 | 原文里的网址；没有就写「未找到」 |
| 更新时间 | 日期 | 年月日 | 你核对或修改这一行的日期 |
| 适合专业 | 文本 |  | 原文没写就填「未找到」 |
| 状态 | 单选 | 未处理、已报名、已放弃 | 你自己的进度。已放弃的行不要参与提醒 |
| 核对状态 | 单选 | 草稿、已核对 | 抽取结果保持草稿，对照原文后再改 |
| 日期原句 | 文本 |  | 原文中含日期说法的那一句，不要改写 |
| 是否参与提醒 | 单选 | 是、否 | 草稿、未找到、已放弃必须为「否」 |
| 报名条件 | 文本 |  | 抽取附加字段。原文没有就「未找到」 |

公式字段「应提醒」在 [飞书自动化](feishu-automation.md) 里创建，不要手填。

## 导入示例

1. 字段按上表建好之后，再导入。日期列如果在导入时被认成文本，删掉该列重建为日期，再贴一次。
2. 多维表格右上角「…」→「导入」→ CSV，选 `templates/feishu-import.example.csv`。编码用 UTF-8。
3. 列名与字段名对齐。导入后应有 10 行。
4. 打开「草稿隔离赛」：核对状态是草稿，是否参与提醒是否。「本周五口头赛」：截止日期为空，截止日期标注是未找到，是否参与提醒是否。

这 10 行用来核对表结构和提醒筛选。你自己的真实通知另录，不要把示例链接当成真实报名入口。

## 手工录入时的最低要求

每一行都要有标题、类型、来源链接（或「未找到」）、更新时间、适合专业、状态、核对状态、日期原句、是否参与提醒。截止日期二选一：公历日期，或标注为未找到并让提醒开关保持「否」。验收要你自己的 10 条真实记录，示例表只证明列是齐的。
