# 十一月中旬上线计划

今天是 2026-11-02。目标是 11 月中旬让别人也能用，而不只是自己在本机看一张表。飞书不再是上线条件。

本地时间线已经能用，命令仍是：

```bash
python3 -m src.timeline --today 2026-11-02
python3 -m src.reminder --today 2026-11-02
```

网页版上线之前，这两条命令和 `data/records.csv` 继续是规则的对照物。日期规则不另写一套。

## 目标

别人注册之后，只能看见和修改自己的竞赛截止。对照原文核对过的公历日期，才会进入今天起 7 天的提醒。没有到期条目的那天不发消息。已经过去的日期在时间线上标成「已过期」。

仓库里现有的 4 条已核对记录（含计挑赛程序设计挑战赛区域赛考试，2026-11-29）是公开示例，用来证明规则。不把它们自动写进每个新用户的「是否参与提醒」。

## 用户

- 使用者是需要竞赛截止提醒的其他人，每人一个账号。
- 本月信息类型仍只做「竞赛」。实习和考研留在配置里，不在这一截一起做。
- 账号之间不互相看见记录。这不是同学社区，也不是投递看板。

## 架构

业务规则留在现有 Python 里：`src/extract.py`、`src/reminder.py`、`src/timeline.py`、`src/validate_records.py`。相对日期写成「未找到」，草稿和不参与提醒的行不能进入提醒。网页不重写这套判断。

| 层 | 选择 | 为什么是这个 |
| --- | --- | --- |
| 后端 | FastAPI | 规则已经是 Python。用它包一层 HTTP，比再把日期逻辑搬进另一种语言更不容易写错。 |
| 数据库 | 先 SQLite，多进程时再换 Postgres | 11 月中旬是一个应用进程。SQLite 一个文件就够，记录表带 `user_id`。要开第二个进程时再迁 Postgres，这一截不同时维护两套库。取舍见 [框架和范围](stack-and-scope.md)。 |
| 前端 | React + Vite | 页面是登录后的清单，不靠服务端渲染找用户。Next.js 能做，但会多一层服务；日期规则若再写进它的接口，就会和 FastAPI 分成两套。本月不选 Next.js。 |
| 账号 | 邮箱 + 密码 | 密码只存哈希。魔法链接要先接发信，11 月中旬不把注册卡在邮件服务商上。发信接好之后可以再加魔法链接。 |
| 部署 | 代码在 Origin，进程在 Railway（或已有的 Fly.io） | Origin 管仓库和 PR，不负责跑网站。Railway 上放一个 FastAPI 进程、Vite 构建出的静态页面，以及一块放 SQLite 的磁盘。已经在用 Fly.io 就用 Fly.io，不必两套都做。 |

飞书多维表格仍可用 `python3 -m src.export_feishu` 导出。它是旁路，不是登录、存储或发送的前提。

## 到 11 月中旬的顺序

1. 本周：恢复本地时间线、3 个来源、4 条已核对记录。不抓网页，不发明日期。
2. 账号已经接上：邮箱和密码注册登录，SQLite 存哈希和会话。未登录不能看时间线。下一步是页面上的手贴，私人记录继续带 user_id。
3. 然后：Vite 页面补手贴。草稿、未找到、已放弃不进 7 天提醒。过期行标成「已过期」。
4. 11 月中旬：部署到 Railway 或 Fly.io。换一个邮箱注册，只能看见自己的记录；没有落在窗口内的行时，不发消息。

## 这一截包括

- 多人账号，记录按人分开。
- 手贴通知。原文是公历年月日才写成 `YYYY-MM-DD`；「本周五」这类或没有日期，截止日期写「未找到」，是否参与提醒为「否」。
- 只有已核对、参与提醒、类型匹配的公历日期进入今天起 7 天。
- 时间线列出剩余天数或「已过期」。
- 信息类型先只做竞赛。
- 飞书导出可选。

## 这一截不包括

- 把定时抓取当成默认录入。来源仍是只手动粘贴。
- 个人微信机器人。本月不做。
- 课程问答、每周复盘、实习和考研的录入。它们属于学习助手，但不是中旬这一截。完成顺序见 [框架和范围](stack-and-scope.md)。
- Coze 或 Dify 的八段抽取考试。那是第二阶段，不挡住 11 月中旬上线。本地 `python3 -m src.score_exam` 仍可用来检查评分表，不算上线条件。
- 根据相对日期换算出某一天。
- 用户之间互看、院校对比、付费。

## 硬规则

- 不发明日期。页面上没有公历年月日，就写「未找到」。
- 本周不把抓网页当成录入方式。
- 抽取结果默认草稿，且不参与提醒。
- 提醒时区仍是 Asia/Shanghai。`reminder_within_days` 仍是 7，不为了演示改宽。
